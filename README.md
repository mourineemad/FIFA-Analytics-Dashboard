# ⚽ FIFA Analytics Dashboard | Power BI

## 📌 Project Overview

An interactive FIFA Analytics Dashboard developed using Microsoft Power BI to explore football tournament data from three different perspectives: tournament performance, stadium infrastructure, and financial distribution.

The dashboard transforms tournament-related data into interactive visualizations and KPIs, allowing users to explore team performance, goals scored, stadium capacities, and financial rewards across different tournament stages and placements.

## 🖼️ Dashboard Preview

### 1. Tournament & Goals Analysis

This page provides an overview of tournament performance, focusing on goals scored, team comparisons, and tournament progression.

**Key Performance Indicators (KPIs):**
- Total Goals.
- Average Goals per Match.
- Maximum Goals per Match.
- Champion.
  
**Visualizations:**
- Total goals by country.
- Goals scored by away team.
- Goals distribution by tournament stage.
- Goals scored by month.
- Goals by group.
- Goals scored by team.

**Interactive Filters:**
- Team
- City
- Country
- Stage Reached
- Stadium Name
- Qualification Route

## 📊 Key Analytical Areas

| Area | Analytical Focus |
|---|---|
| Tournament Performance | Goals, teams, groups, and stages |
| Team Analysis | Goals scored and team comparisons |
| Tournament Progression | Performance by stage reached |
| Stadium Infrastructure | Capacity, locations, and roof types |
| Stadium Utilization | Matches hosted per stadium |
| Financial Analysis | Prize payouts and preparation fees |
| Prize Distribution | Rewards by placement and tournament stage |
